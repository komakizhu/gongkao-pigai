# 赋分来源与取舍说明

研究日期：2026-10-16。国考及多数省考不公开完整逐题赋分表，以下内容只用于选择透明、可修改的参考系数，不代表官方成绩算法。

## 采用的参考

- [华图：2026国家公务员考试行测答题技巧、分值分布](https://gd.huatu.com/2025/1011/10563139.html)：公开六模块/题型的参考单题分值，明确声明不是官方标准。`weights.json` 的 `huatu-six-v1` 采用其政治理论、常识、言语、数量、资料系数，并将判断推理子题型参考总分折算为模块平均系数 `28.5 / 35 = 57 / 70`。
- [华图：27国考行测六大模块备考顺序](https://ha.huatu.com/2026/0917/6821353.html)：明确指出政治理论自 2025 年国考起单列，并给出六模块估算分值；用于 `assumption-six-v1` 的相对系数参考，未宣称是正式机构模型。
- [粉笔：模考大赛 Q&A](https://www.fenbi.com/page/mokaodasai-qa)：公开说明因官方不公布具体模块赋分，模考采用“均分微调制”，但没有提供可独立复现的完整微调系数。因此不把粉笔名称写入默认模型，也不猜测其内部参数。
- [中公：历年广东公务员考试行测分值分布分析](https://www.eoffcn.com/bkzl/ksjq/156595.html)：提供 2020 年广东省考特定卷型的参考分值，并明确官网没有标准分值分布。该表只作为地区/年份案例，不直接用于国考默认权重。
- [《教育与考试》：改善新高考学考评价的教育测量学探索](https://jyks.cbpt.cnki.net/portal/journal/portal/client/paper/c2dcb1f59296da1cdc2b7900a60b0397)：讨论经典测量理论与项目反应理论在标准化考试评价中的用途。它没有提供行测逐题参数，因此只作为方法背景，不被脚本转换成行测权重。

## 排除和不确定性

部分“2026”页面仍沿用政治理论单列前的五模块结构，另有六模块页面的模块总分合计不一致。脚本不会根据页面标题或题号猜测适用模型；只有考试信息、类别和模块题量同时满足配置条件时才自动选用华图派生模型，否则使用明确标注为假设的模型或用户指定模型。所有模型都会在 JSON 和 Markdown 报告中保留名称、版本、来源、研究日期和不确定性。
