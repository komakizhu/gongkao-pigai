# 材料整理说明

## 来源保留

提取阶段先保存原始文本，再做答案结构化。Markdown 使用 `## 第 N 页`、`### 段落 N` 或 `| 表格 |` 等标记，`extraction.json` 的 `sources` 记录文件、页码、段落或表格位置。扫描内容必须保留页面引用和 `needs_review` 状态。

原始材料中的“第一部分/第二部分”、章节标题、子模块标题和题号范围属于必须保留的结构化信息。整理答案行时不能只留下“题号 + 答案”而丢掉标题；应建立逐题 `section` 映射，并在私有答案集、公开配置和单文件答题卡中持续传递。对于多分区材料，单一全局 `--section` 不足以表达题目归属，必须分区处理或使用逐题映射。

## 严格解析

答案行必须有明确题号和答案，例如：

```text
41 C
42 A,C
43 对
```

不得从普通正文中搜集单个字母。单选、多选和判断必须由材料或用户声明，不能由答案数量推断。题号重复、相同题号答案冲突、题型不明、选项范围不明和识别低置信度都要进入 `issues`。

模块完整性也是阻断条件：如果提取稿明确有模块标题，但任意题目无法映射到非空、已确认的 `section`，不得生成答题卡配置或 HTML；必须先补齐映射并核对范围无遗漏、无重叠。否则会出现答题卡可以使用、批改可以判题，但估分阶段才暴露 `missing_module` 的 Bad Case。

## 隐私边界

`answer-set.json` 是私有资料，包含参考答案和来源；`answer-recorder-config` 是公开资料，只包含题目身份、题号、题型和选项。私有答案不进入 `public/`、`dist/`、Service Worker 缓存或 iPad 网页配置。
